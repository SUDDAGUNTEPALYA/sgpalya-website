GOOGLE FORM
The Register Your Business button links to the S.G. PALYA Google Form.
Form responses are managed separately in the connected Google Sheets spreadsheet.

UPLOAD TO THE EXISTING GITHUB REPOSITORY
1. Extract this ZIP into a NEW folder on your Windows computer.
2. Open the extracted folder. The six files should be visible directly inside it.
3. Open the existing public repository: sgpalya-website.
4. Choose Add file > Upload files.
5. Select all six files from the extracted folder and drag them into GitHub.
6. GitHub will replace files with matching names and add the profile photo.
7. Click Commit changes.
8. Wait for GitHub Pages to finish deploying, then check https://sgpalya.in.

IMPORTANT
- Upload the six individual files, not the ZIP itself.
- Keep all six files together in the repository root (not inside another folder).
- Do not delete the GitHub repository.
- Do not change GoDaddy DNS records or the GitHub Pages custom-domain setting.
- The package does not add real business listings; add only verified listings with permission.

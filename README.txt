S.G. PALYA WEBSITE STARTER

This is a responsive static website, not a PowerPoint or Google Sites import.
Google Sites cannot import a complete HTML website.

FILES
- index.html: page content
- style.css: responsive design
- script.js: mobile menu and basic category/search interaction
- CNAME: custom domain name

BEFORE LAUNCH
The directory deliberately contains no invented business listings.
The registration button currently opens an email to hello@sgpalya.in.
Set up that mailbox or replace the address in index.html with your Google Form link.

FREE PUBLISHING ROUTE: GITHUB PAGES
1. Sign in/create a GitHub account.
2. Create a PUBLIC repository named sgpalya-website.
3. Upload index.html, style.css, script.js and CNAME.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. Verify the free GitHub Pages address works.
7. In GoDaddy DNS for sgpalya.in, add the DNS records specified by GitHub Pages custom-domain instructions. Do not delete existing DNS records blindly.
8. Enter sgpalya.in in GitHub Pages custom domain settings and enable HTTPS after verification.

This package does not itself publish the website or change GoDaddy DNS.
